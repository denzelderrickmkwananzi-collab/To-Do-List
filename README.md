# Today Task Dashboard

A modern, responsive, three-card productivity and to-do list web application built with **HTML5**, **CSS3**, and **Vanilla JavaScript**. Designed with a clean UI, it combines task management, priority tagging, focus sessions, and local browser persistence without requiring any external frameworks or backend setup.

---

## What the Project Does

The **Today Task Dashboard** provides an intuitive workspace for planning and tracking daily tasks:

* **Task Management:** Add new tasks inline, mark tasks as completed via custom checkboxes, and delete items effortlessly.
* **Dynamic Priority Labels:** Categorize tasks with color-coded priority levels (**High**, **Medium**, **Low**) that can be updated on the fly.
* **Focus Mode:** Dim non-essential dashboard cards so you can concentrate exclusively on your active task list.
* **AI Assist (Quick Suggestions):** Generate and append instant, actionable task suggestions with a single click.
* **Session Metrics:** Calculate an **Overall Impact Score** and **Ideal Session Length** based on completed tasks when you click **Finish**.
* **Automatic Persistence:** Saves all tasks, completion states, and priority changes automatically in the browser using `localStorage`.

## How to Get Started

### Prerequisites
You only need a modern web browser (e.g., Chrome, Edge, Firefox, Safari) and a code editor such as [VS Code](https://visualstudio.com).


## 🛠️ Usage Guide

1. **Add a Task:** Click the **`+ Add Task`** button at the bottom of the task card, enter your task description, choose a priority level, and click **Save**.
2. **Update Priority:** Use the inline pill dropdown (`High`, `Medium`, `Low`) on the right side of any task row to adjust urgency.
3. **Complete or Remove Tasks:** Click the checkbox on the left to mark a task complete, or click the trash icon on the right to delete it.
4. **Enter Focus Mode:** Click **`Focus Mode`** in the top-right header of the task card to dim surrounding dashboard cards.
5. **Calculate Session Summary:** Click **`Finish`** to update your **Overall Impact Score** and **Ideal Session Length** in the profile card above.
